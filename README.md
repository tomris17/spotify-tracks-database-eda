This repository contains an exploratory data analysis (EDA) project focusing on Spotify tracks metadata, audio features (such as danceability, energy, valence, and tempo), and track popularity metrics.

---

## 📊 Project Overview
* **Objective:** Uncover statistical patterns and correlations between audio attributes and track popularity on Spotify.
* **Key Steps:**
  * Data cleaning, handling missing values, and filtering audio feature ranges.
  * Statistical aggregation and correlation analysis between musical properties (e.g., energy vs. valence, danceability vs. popularity).
  * Genre and artist-based trend visualizations.
  * Interactive web dashboard deployment via **Streamlit** to filter and explore track statistics dynamically.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy** (Data Cleaning & Aggregation)
* **Matplotlib & Seaborn** (Statistical Charts & Visualizations)
* **Streamlit** (Interactive Dashboard)
